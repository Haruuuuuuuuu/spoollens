## Reproduction

Requires Linux or macOS with Python 3.10+; the recorded environment was Linux/Python 3.12.14. No network or third-party Python packages are required. Use the exact candidate code and its unchanged `tests/fixtures` directory. The packaged test-count assertion intentionally remains fixed at the original candidate's 41 tests.

First verify the package itself:

```sh
cd /path/to/portable
sha256sum -c SHA256SUMS
```

Create a disposable archive of the verified commit and an isolated virtual environment:

```sh
WORK=$(mktemp -d)
mkdir "$WORK/candidate"
git -C /path/to/astra-lab-spoollens archive \
  0f04a3ae959460721b0b2142acb72306d2c7ec15 | tar -x -C "$WORK/candidate"
python3 -m venv "$WORK/venv"
python3 /path/to/portable/run_blackbox.py \
  --candidate "$WORK/candidate" \
  --fixtures "$WORK/candidate/tests/fixtures" \
  --python "$WORK/venv/bin/python" \
  --sha 0f04a3ae959460721b0b2142acb72306d2c7ec15 \
  --out "$WORK/results"
```

The results directory must be new. `--variations` is optional and defaults to the bundled `predeclared` directory. The supplied `--sha` is recorded as provenance; the caller must archive/check out that exact commit as shown above. Successful completion prints `ALL PASS 36 check groups` and writes reports, invocation logs, CSVs, exception ZIPs, accounting and provenance under the requested results directory.

Only path configuration changed in the portable script: frozen fixtures are passed explicitly, and variation location can be overridden. Assertions, expected values, extraction invocations and comparison logic are unchanged. No original result was overwritten or relabeled as a newer test.
